# 📷 网站背景图片

把照片丢进这个文件夹，网站就会自动把它作为全站背景。

## 怎么用

**方式一（推荐，零配置）**：用本地服务打开网站时，直接往这里放照片，
刷新页面即生效 —— 会自动使用本文件夹里**第一张**图片（按文件名排序）。
多放几张就切换时，把想用的那张文件名改成最小的（如 `a.jpg`）即可。

**方式二（精确指定）**：在 `config.js` 里设置：

```js
background: 'assets/backgrounds/my-photo.jpg',
```

留空（`''`）则回到默认的浅蓝渐变背景。

## 小贴士

- 支持格式：`png / jpg / jpeg / gif / webp / avif / svg`
- 建议用 **横图**（1920×1080 或更宽），竖图会被裁切成铺满
- 照片会垫一层半透明白色纱幕，保证正文始终清晰可读
- 想换回默认渐变背景：删掉本文件夹里的图片，或在 `config.js` 里把 `background` 留空
