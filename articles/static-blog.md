经常有人问我：博客用什么框架？我的回答是 —— **一个文件夹就够了**。

## 纯静态的优势

| 维度 | 纯静态 | 动态框架 |
| --- | --- | --- |
| 部署 | 任何托管都能跑 | 需要 Node/PHP 环境 |
| 速度 | 秒开 | 依赖服务器性能 |
| 维护 | 几乎为零 | 需要持续更新依赖 |
| 可控 | 每一行都懂 | 黑盒较多 |

**最重要的**：十年后打开这个文件夹，它依然能跑。这就是长期主义的魅力。

## 发文流程

我给自己设计了两种发文方式：

- [x] 网页后台在线写作，保存即生效
- [x] 本地写 `.md` 文件，丢进文件夹自动更新
- [ ] ~~复杂的管理系统~~（不需要）

## 一点心得

> 工具越简单，内容越重要。

写博客的核心不是技术选型，而是 **持续输出**。选择最不容易放弃的方案，才能写得久。

```bash
# 启动本地服务，就这么简单
node tools/serve.mjs
```

纯静态不等于简陋 —— 零依赖的网站也可以很炫酷。这篇博客本身就是证明 🚀
