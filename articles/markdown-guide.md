写文章最重要的是专注内容，而 **Markdown** 让排版变得毫不费力。这篇是本站的写作语法速查。

## 基础语法

### 标题与强调

```markdown
# 一级标题
## 二级标题
### 三级标题

**加粗**、*斜体*、~~删除线~~、==高亮==、`行内代码`
```

### 列表

```markdown
- 无序列表项
- 另一个列表项

1. 有序列表项
2. 第二个有序项

- [x] 已完成的任务
- [ ] 未完成的任务
```

- [x] 学会标题
- [x] 学会强调
- [ ] 学会表格

### 链接与引用

```markdown
[链接文字](https://example.com)

> 这是一段引用文字
```

> 纸上得来终觉浅，绝知此事要躬行。

## 小技巧

1. 标题会自动生成**目录**，右侧即可跳转
2. 行尾加**两个空格**可以换行
3. 图片可以直接写 `![](图片地址)`
